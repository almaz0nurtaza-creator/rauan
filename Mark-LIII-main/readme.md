# ⚙️ MARK LIII (53)
### Кроссплатформенный персональный ИИ-ассистент

> Оригинальный проект создан **FatihMakes** — [YouTube-канал](https://www.youtube.com/@FatihMakes)

Голосовой ИИ-ассистент реального времени, который слышит, видит, понимает и управляет вашим компьютером — на любой ОС. Поддерживает Windows, macOS и Linux. Построен на Gemini Live API для нативной потоковой передачи аудио — без подписок и с полной цифровой автономией.

---

## ✨ Обзор

**MARK LIII — версия, ориентированная на голосовое управление и масштабируемость.** Скажите **«Hey Jarvis»** — и ассистент проснётся; помолчите немного — и он сам уснёт. Пока ассистент «спит», микрофон не передаёт звук наружу, поэтому случайная фраза в комнате его не разбудит. Под капотом теперь используется более быстрый движок **Gemini 3.1 Flash Live**, а на длительные запросы (анализ файла, поиск в интернете) ассистент сразу отвечает короткой фразой вроде *«Секунду, сейчас посмотрю»*, чтобы не было ощущения тишины.

Архитектура рассчитана на расширение: каждый навык — встроенный или добавленный вручную — описывает сам себя в отдельном файле, поэтому подключение нового инструмента — это просто добавление одного файла.

## ⚡ Быстрый старт

```bash
git clone https://github.com/almaz0nurtaza-creator/rauan.git
cd rauan/Mark-LIII-main
python setup.py        # установит зависимости под вашу ОС
python main.py
```

> ⚠️ Если появится `ModuleNotFoundError` для системного пакета — установите его через `pip install <название_модуля>`. Функция **wake word** устанавливается отдельно, одним кликом, через меню **⚙ → WAKE WORD** внутри приложения.

## 🗂️ Структура проекта

```
Mark-LIII-main/
├── main.py         # Основной цикл — сессия Gemini Live, аудио, состояние сна/бодрствования
├── ui.py            # Интерфейс на PyQt6
├── setup.py         # Установщик зависимостей под вашу ОС
├── plugins/         # Пользовательские плагины
├── actions/         # Встроенные навыки ассистента
├── memory/          # Хранилище памяти и настроек
├── core/            # Логика подтверждений, отмены действий, аудио и т.д.
└── config/          # Конфигурация: ключи API, имя, голос, цвет интерфейса
```
